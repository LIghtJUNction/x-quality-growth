# 曝光下降后的恢复实验

目标是找回同领域真实受众看到、阅读并愿意交流的内容。先分清“帖子浏览量下降”和“总粉丝净增变慢”：它们可以同时发生，也可能只有一个发生。`diagnose_growth.py` 测的是总粉丝净变化速度，不能诊断帖子曝光，更不能证明限流或内容质量下降。

可在已登录浏览器检查官方 [Under the Hood](https://x.com/i/jf/under_the_hood) 报告，记录报告期、生成时间和实际标签。这是有资格限制的月度试点报告；入口不可用不代表限流，历史月份显示无标签也不证明今天没有限制。代码依据与资格条件见官方 [报告服务](https://github.com/xai-org/x-algorithm/blob/78460ca8b65c57ddd3a05f9217c8aaeba214b628/under-the-hood/strato/columns/underTheHoodReport.User.strato#L500-L524)。

## 先记录可比较基线

1. 核对最近原创帖是否实际发布，重新打开永久链接确认正文、媒体和回复仍存在。记录发布时间、主题、形式、发帖者及当时行动预算；出现界面限制或保存失败如实记录，不当作曝光实验完成。
2. 选择主题、内容形式、发布时间段相近的原创帖作为候选对照。每条帖分别在发布后 **60 分钟、24 小时**采集可见浏览、回复、点赞、转贴和收藏。比较同龄帖、同长度窗口；不能把刚发的帖和昨天积累一天的帖直接比。缺旧帖的同龄采集记录，就从本轮建立基线，不用其当前总数冒充历史时点。
3. 每次记录该帖真实采集时刻和采集时的帖子年龄。没按时检查就记录实际年龄，标为窗口未对齐；不回填计划时刻。没有真实调度器时，写下待复查时间及未配置后台检查，不承诺 24 小时后自动执行。
4. 公开浏览量是平台可见计数，不等于独立访客、完整阅读人数或可验证推荐曝光。不可见的 impressions、主页访问、帖子带来的关注、负反馈保持 null。浏览、粉丝名单和 GitHub 热度分别保留观察时间，不能拼成一个“归因窗口”。

真实记录写在忽略的 `runs/`，例如：

```json
{
  "experiment": "reach-recovery-01",
  "variable": "开头直接给可复用结果",
  "topic": "可验证的 AI 编程与独立开发案例",
  "action_budget": {"original_posts": 1, "substantive_replies": 2},
  "post_url": null,
  "published_at": null,
  "planned_observation_ages_minutes": [60, 1440],
  "observations": [],
  "concurrent_operations": "据实记录，未知不能写无",
  "scheduler_configured": false
}
```

该示例是记录结构，不是实测结果，不可直接填入公开指标。真实帖子链接应符合本账号永久链接规范。

## 一轮实际执行

在已有用户授权内发布 **1 条主题匹配的原创内容**：第一段给可验证结果，正文给具体步骤、作品、证据或读者能复用的资源。选择目标受众真正有问题的讨论，读完原帖再补充最多 2 条不同讨论的实质回复；优先回应已收到的真人具体问题。不批量无关回复，不复制互关模板，不承诺关注换关注，不用重复介绍技能填满内容。数字是本轮工作预算，可由用户调整，不能称为平台安全阈值。

如果已有原创案例和公共复现资料，而没有新结果，允许把下一轮预算改为定向交流，明确记录原创帖 0：寻找真实同领域工作流中的一个具体缺口，读原帖后提供针对该缺口的复现帮助。按回复首次发布时刻独立观察，区分作者的简短肯定、实质方法反馈与关注变化；自己的评论和主动关注不计为获客成果。没有新价值不重复原案例。

每轮只改一个主要变量，例如开头、案例选题、内容形式或发布时间。其余条件尽量相近，记下不可控制的并行运营、受众差异及帖子年龄。先确认每次发布或回复保存成功，随后按 60 分钟和 24 小时窗口观察；24 小时没到就只报告早期观察，不提前判断恢复。不要为了测试互动效果自己重复点赞、收藏或回复制造计数。

## 观察什么才值得下一轮保留

- **曝光：** 同龄帖可见浏览计数及同帖固定窗口增量，保留实际窗口。计数减少、旧基线缺失或时刻未推进时，先核对，不把错误相减当成恢复效果。
- **独立实质互动：** 阅读可见回复，记录非本账号的实质问题、补充方法或作品交流及证据链接。看不到互动者身份时，不把公开点赞总数自动称为非自身互动；无法分离自操作则标“独立受众互动未知”。
- **主页与粉丝：** 主页转化不可见就留 null。新增蓝 V 与高质量新增按测量规范核验，不能用总粉丝净增或老粉升标代替；分类未知保留在分母和上下界中。

在行动前写下比较指标与基线：例如同龄浏览、独立实质回复数、确认新增蓝 V 数和高质量人数。不要看到结果后重新选择最漂亮的指标。曝光上升而质量未变、数量上升而质量下降，分别报告，不宣布所有目标一起改善。

窗口结束后，只有同龄浏览与真实互动有可核验改善，才能写“这一轮观察到改善”；仍不是推荐算法因果证明，也不是长期恢复。数据不足、窗口不匹配、无改善或存在未控制运营时，写“尚未证实恢复”，保留记录，下一轮换一个有证据支持的变量。短窗口、小样本或粉丝增速下降不足以认定限流；开源互动权重不能直接解释本账号结果。

实际回退或明确限制时停止对应失败动作，继续正常阅读、原创内容和测量；不得用换账号、隐藏接口、无意义重试或更大机械行动量来“修复流量”。
