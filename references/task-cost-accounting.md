# Agent 任务成本记录：可复制模板

这是账务与验收模板，不是已完成的 benchmark，也不提供模型价格或优劣结论。

## 开始前填好

```text
比较批次：____；任务集合/输入版本：____；币种：____
组 A / B 配置版本：____；各组预算：____
记录区间：[开始时间____，结束时间____]；时区：____
同任务 ID 的难度、起始环境、工具权限：____
逐任务验收条件：____；每任务自主尝试上限：____
每任务自主时间上限：____；提前停止条件：____
允许的人工救援/停止规则：____（两组一致，救援另记阶段）
```

两组跑同一批任务，各自从相同的干净起点开始；不要给其中一组换简单题。
自主尝试次数不是 API 调用次数；一次尝试可有多次调用。

## 每次尝试记一行

```text
组,任务ID,阶段(自主/救援),尝试序号,开始,结束,API调用数,API费用,验收(通过/失败/未知),人工分钟,备注
____,____,____,____,____,____,____,____,____,____,____
```

失败、超时、重试及救援阶段的 API 费用都保留；费用缺记录则记 unknown，不补 0。
同一任务重试通过仍只计一个完成；救援后通过不能改写成自主通过。
每组另报任务总数、自主通过数、仅救援通过数、未通过数、验收未知数。
记录实际开始/结束区间与逐任务完整耗时；人工分钟是劳动时间，不是全流程耗时。

## 算三个结果

1. **全轮 API 支出**＝自主阶段全部费用＋救援阶段全部费用。
2. **自主阶段 API 支出 / 自主通过任务数**：分子包含自主阶段全部失败和重试。
3. **全轮 API 支出 / 全部通过任务数**：全部通过＝自主通过＋仅救援通过。

两种单位成功成本的分子范围不同，保留完整名称；人工分钟和人工计价另列。
API 支出不是包含人工、工具订阅与机器费用的总成本；缺计价就不声称总成本。
通过数为 0 时，对应比值为 undefined/null，保留实际支出和 0 完成，不能报 0 成本。
费用或验收不完整时完整比值也为 null；完成数按独立任务 ID 去重，不按调用数算。
保留逐任务结果，汇总旁列费用/耗时范围与最大值；均值不能替代失败和尾部记录。

## 合成算术演示，非 X 或模型实测

以下金额仅是合成美元，不对应任何模型定价。两组同为 T1/T2/T3，任务等权；自主最多尝试 2 次，可提前停止；救援单列。调用数、完整时间区间和耗时未给出，均为 unknown。

| 组 | 任务 | 自主尝试：费用与验收 | 救援 API 费用与验收 | 人工分钟 |
| --- | --- | --- | --- | ---: |
| A | T1 | 0.30 通过 | 无 | 0 |
| A | T2 | 0.20 失败；0.35 通过 | 无 | 0 |
| A | T3 | 0.40 失败并停止 | 0.10 通过 | 10 |
| B | T1 | 0.20 通过 | 无 | 0 |
| B | T2 | 0.15 失败；0.25 失败并停止 | 无 | 0 |
| B | T3 | 0.30 通过 | 无 | 0 |

A：自主通过 2/3、救回 1、未通过 0；三个结果为 **1.35、0.625、0.450**。
B：自主通过 2/3、救回 0、未通过 1；三个结果为 **0.90、0.450、0.450**。
后两项单位为美元/通过任务。A 人工 10 分钟，B 为 0；相同的 0.450 不证明效率相同。
逐任务总费用范围：A 0.30–0.55（最大 0.55），B 0.20–0.40（最大 0.40）；耗时尾部未知。

用标准库 Python 复核上述三项；金额先用整数美分相加：

```python
rows = [  # 组, ID, 自主各次美分, 自主通过, 救援美分, 救援通过
    ("A", "T1", [30], True, 0, False), ("A", "T2", [20, 35], True, 0, False),
    ("A", "T3", [40], False, 10, True),
    ("B", "T1", [20], True, 0, False), ("B", "T2", [15, 25], False, 0, False),
    ("B", "T3", [30], True, 0, False),
]
ratio = lambda cents, n: round(cents / 100 / n, 3) if n else None
for group in ("A", "B"):
    r = [x for x in rows if x[0] == group]
    auto = sum(sum(x[2]) for x in r)
    total = auto + sum(x[4] for x in r)
    print(group, total / 100, ratio(auto, sum(x[3] for x in r)),
          ratio(total, sum(x[3] or x[5] for x in r)))
```

三题合成数据只验证算术，不能证明能力胜负、真实预算吞吐量或稳定的尾部表现。
